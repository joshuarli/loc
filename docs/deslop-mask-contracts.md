# Mask scanner qualification

The component is `src/analysis/masks.rs`. `count_text` in `src/analysis/line_counter.rs` uses the scanner after the first line, both in clear classifier state for code and in an open comment or string with its closing marker bytes. It falls back to line search when markers do not suit the scanner or the machine lacks the features. The existing marker-transition regression checks a changed search in the same block; `sweep_counts_tails_and_stops_on_markers_at_byte_boundaries` adds literal code, comment and blank counts, a marker transition, and an unterminated last line at lengths around 16, 32, 64 and 128 bytes.
